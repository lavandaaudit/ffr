# IBONARIUM: KYIV — THE LAST SIGNAL
## Місія 01 «ОБОЛОНЬ: ПЕРШИЙ ДЕНЬ» — демо-білд для Sega Mega Drive / Genesis

Ізометричний зомбі--survival action RPG у стилі класики 16-бітової епохи.
Марко, 36-річний киянин, прокидається 07:42 у своїй квартирі на Оболоні.
Місто мертве. Дзвоник мовчить. Треба знайти воду, ніж, вихід із під'їзду —
і сигнал, який нічого не має бути...

Ром зібрано **SGDK** (Sega Development Kit) з C-джерел у цьому репозиторії.

---

## ▶ Як запустити (найшвидший спосіб)

1. Завантажте весь репозиторій (ZIP або `git clone`).
2. Опублікуйте його як GitHub Pages (або відкрийте локально через
   `python -m http.server` — див. нижче).
3. Відкрийте `index.html` — гра завантажиться прямо в браузері.

**Локально без GitHub:**

```bash
cd IBONARIUM_KYIV
python3 -m http.server 8080
# відкрийте http://localhost:8080
```

> Не відкривайте index.html просто подвійним кліком (file://) — браузер
> блокує завантаження ром для file:// сторінок. Потрібен HTTP-сервер.

**Готовий ROM лежить у корені: `rom.bin`** (131072 байт, checksum OK).
Його також можна запускати в BlastEm, Genesis Plus GX, Kega Fusion
або на реальній Mega Drive ( Everdrive ).

## 📋 Що реалізовано в Місії 01

- **Зона 1 — Квартира:** телефон (без сигналу), телевізор (розбитий),
  радіо (шипіння), холодильник (→ ВОДА), кухонна стільниця (→ КУХОННИЙ НІЖ),
  шафа (→ БИНТ), ліжко, диван, стіл. Марко прокидається на підлозі.
- **Зона 2 — Під'їзд:** темна димáрка з кров'ю, уламками й першим WALKER.
- **Зона 3 — Двір Оболоні:** панельні будинки з вікнами, дерева, дитячий
  майданчик (гойдалка/гірка/качелі), лавки, урни, фонарі, брошені машини
  (ВАЗ-2101, Daewoo Lanos → ВОДА, Skoda, мікроавтобус (палить) → БАТАРЕЙКИ,
  урна → МЕТАЛЕВІ ДЕТАЛІ). Вороги: **RUNNER** (швидкий) і **SCREAMER**
  (кричить і скликає всіх заражених).
- **Зона 4 — Площа з парканом:** бос **BRUTE** (великий, повільний,
  важкий удар, багато HP), а за ним — старий радіоприймач.
- **Фінал:** SIGNAL DETECTED → «...якщо хтось мене чує... повторюю...
  це не випадковість...» → «IBONARIUM...» → «Що таке IBONARIUM?..» →
  MISSION COMPLETED / THE SIGNAL HAS FOUND YOU → автозбереження в SRAM.
- **Завдання HUD:** ЗАВДАННЯ ОНОВЛЕНО · ЗНАЙДІТЬ ВОДУ · ЗНАЙДІТЬ КУХОННИЙ НІЖ ·
  ЗНАЙДІТЬ ВИХІД ІЗ ПІД'ЇЗДУ · НЕБЕЗПЕКА ПОБЛИЗУ · SIGNAL DETECTED.
- **Система виживання:** HP, витривалість (біг/атаки), голод і спрага
  (на нулі — втрата HP), травми (уповільнюють рух, лікуються бинтом/аптечкою).
- **Інвентар:** 12 слотів + зброя, іконки, кількість, опис, використання речей.
- **SRAM-збереження:** «ЗБЕРЕГТИ» в паузі + автосейв після фіналу,
  «ПРОДОВЖИТИ» на титульному екрані.
- **Звук:** PSG-бібліотека ефектів (ножи, удари, крики, статичне радіо,
  морзянка фіналу), вітер у дворі. PLACEHOLDER-дизайн звуку.

## 🛠 Збірка з джерел

Потрібен [SGDK](https://github.com/Stephane-D/SGDK) (v2.x) + m68k тулчейн.

```bash
# Windows: встановіть SGDK, далі
make -f makefile.gen release

# Linux (без root): тулчейн m68k-linux-gnu-gcc (+ обгортки m68k-elf-*),
# sjasm 0.39h, bintos, convsym (будуються з tools/ у SGDK).
# УВАГА: у makefile.gen додано -Wl,--build-id=none — це потрібно лиш
# для Linux-драйвера GCC (бо m68k-linux-gnu gcc додає .note.gnu.build-id).
GDK=/шлях/до/sgdk make -f makefile.gen release
# результат: out/rom.bin
```

Скрипти генератора ресурсів (Python + PIL, не потрібні для перескладки —
готові PNG вже в res/):
- `scripts/gen_world.py` — будує ізометричну мапу + дані колізій/об'єктів;
- `scripts/gen_sprites.py` — шрифти (кирилиця), HUD-тайли, спрайти.

## 🖼 PLACEHOLDER-графіка

Уся графіка і звук — **згенеровані PLACEHOLDER'и** (метадані в рядках,
піксель-арт програмно). Для фінального білду треба замінити:
- `world.png` — намальований ізометричний тайлсет Оболоні (32×16 ромби,
  панельні будинки з реальними вікнами/балконами, авт, дерев);
- спрайти Марко (потребує 8 напрямків замість 4+flip), WALKER/RUNNER/
  SCREAMER/BRUTE (липові контури);
- шрифтові гліфи — на авторські (зараз DejaVu Sans Bold 9px);
- звук — на YM2612 музику та PCM-семпли (зараз PSG-синтез).

## 📝 Технічні деталі

- Роздільність 320×224, 4 палітри × 16 кольорів;
- VRAM: мапа тайлів 96..844, шрифти 860..1467, HUD 1480+, спрайти 1532+;
- ізометрія: sx = (u−v)·16, sy = (u+v)·8; деп sorted через SPR_setZ;
- мапа 1568×848 px стрімиться SGDK MAP-двигуном (план 64×32 тайлів);
- колізії — 48×48 клітинок (world_block), радіус 0.2 клітинки;
- звук — PSG (SN76489) через PSG_setTone/PSG_setEnvelope/PSG_setNoise;
- сейв — SRAM 0x200000, структура 44 байти з checksum.
